Third-party notices — Python dependencies
=========================================

The service redistributes its Python dependencies only inside the Docker image,
where each one carries its own licence text in its `.dist-info` directory and
needs nothing from this file. The wheel published to PyPI redistributes none of
them: it declares them, and the installer fetches each from PyPI complete with
its own licence.

Listed below are the exceptions — packages whose published wheel omits the
licence file its own metadata claims, so the text cannot travel with the code
on its own. Verified against a built image; re-check when dependencies move,
and delete an entry once upstream ships its licence again.

The admin UI is a separate case and has its own file: the bundler merges its
dependencies into one minified file and strips their notices, so they are
regenerated at build time into `ui_dist/THIRD-PARTY-NOTICES.txt`.
