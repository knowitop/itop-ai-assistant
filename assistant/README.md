# itop-ai-assistant

Python service that adds an AI layer on top of the
[Combodo iTop](https://www.itophub.io/) ITSM platform.

This directory is the Python distribution: the package lives in
`src/itop_ai_assistant/`, the tests in `test/`.

Full documentation — installation, configuration, iTop setup and the admin UI —
is in the [repository README](../README.md) and under [`docs/`](../docs).
